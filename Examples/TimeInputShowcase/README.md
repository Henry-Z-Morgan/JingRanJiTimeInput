# TimeInputShowcase

这是公开配置的 SwiftUI 示例，不属于 `JingRanJiTimeInput` 库产物，也不会被消费者自动链接。

## 运行

1. 在 Xcode 新建一个 iOS 16+ SwiftUI App。
2. 通过 Swift Package Manager 添加本仓库。
3. 用本目录的 `TimeInputShowcaseApp.swift` **替换**新工程自动生成的 `YourAppApp.swift`，再加入 `TimeInputShowcaseView.swift`。
4. 运行该 App Target。

示例覆盖：中性默认样式、颜色替换、数字字体与行高、选中条高度/圆角，以及拖动滚轮时键盘是否收起。
